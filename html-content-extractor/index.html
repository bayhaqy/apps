HTML Content Extractor

Pull clean, readable article content out of any web page — Medium, WordPress, Blogger, Substack, Dev.to, Hashnode, Ghost, news sites and beyond, not just Medium. Paste raw HTML, upload a saved page, or fetch a URL through a public relay. Get a distraction-free reader view plus Markdown, plain text and clean HTML export, with metadata, word count and reading time.

Source

URL fetching goes through free public CORS relays (allorigins → codetabs). Many sites allow it; some block relays. If nothing comes back, open the page, press Ctrl+U, copy all and use Paste HTML — always works.

Engine & options

Auto mode applies site-specific rules per platform, then falls back to the Firefox Reader View algorithm (Mozilla Readability) — whichever extracts more text wins.

Everything runs locally in your browser. No page content is ever uploaded anywhere.

Extracted text looks very short — the page may be JavaScript-rendered or paywalled. Try another platform preset, or paste the raw HTML (Ctrl+U → copy → paste).
