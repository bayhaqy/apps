# Bayhaqy Apps

> **Your Swiss Army knife of web tools** — an all-in-one collection of **55 fast, private,
> browser-based tools** across 8 categories: network, security, developer, design, PDF, AI,
> media, and everyday utilities.
>
> Built for developers, IT pros, students, and creators — handy for anyone. All tools run
> entirely in your browser: no installs, no accounts, no tracking of your data.

🌐 **Live site:** <https://bayhaqy.my.id/apps/>

---

## Why Bayhaqy Apps?

- ⚡ **Instant** — every tool loads in your browser. No sign-up, no setup.
- 🔒 **Private** — your data never leaves your machine. All processing is client-side.
- 🆓 **Free** — no paywalls, no premium tiers. Non-intrusive ads keep the hosting online.
- 🧰 **All-in-one** — one toolbox for everything: network diagnostics, PDF editing, AI helpers,
  image tools, calculators, and more. No need to hunt for a different website per task.
- 📱 **Installable** — add to home screen on iOS or install the APK on Android.
- 🎨 **Consistent** — one shared theme (red / black / white) across all 55 tools.
- 👁️ **Transparent traffic stats** — every page shows its public view counter.
- 🤝 **Contribution-friendly** — every tool page links directly to "report a bug or suggest
  an improvement" on GitHub.

## Site features

### SEO
- Unique `<title>`, meta description, canonical URL, robots, Open Graph, and Twitter Card
  on **every page** (landing + 55 tools + get-app + API docs).
- JSON-LD structured data: `WebSite` + `Person` + `CollectionPage` + `ItemList` on the
  landing page; `BreadcrumbList` + `WebApplication` on every tool page.
- [`sitemap.xml`](sitemap.xml) with 58 URLs, [`robots.txt`](robots.txt), and root
  [`ads.txt`](ads.txt) for AdSense.

### Analytics
- **Google Analytics 4** (`G-8GJ1M5ZLZS`) via gtag.js — lazy-loaded after first scroll.
- **Microsoft Clarity** (`jgxsse2i1y`) session insights.

### Ads
- **Google AdSense** display units (`ca-pub-6391433517652109`, slot `2762790866`):
  2 units on the landing page (hero + bottom), 1 unit per tool page.
- Ad script loads lazily (first scroll / 4 s fallback) to protect Lighthouse scores.

### Traffic counters (public views)
- Every page shows **"👁 N views"** in the footer, powered by the public
  [Abacus counter API](https://abacus.jasoncameron.dev) — no cookies, no PII, no accounts.
- The landing page shows the total view count; each tool counts its own views
  (key = tool slug, namespace `bayhaqy-apps`).
- The counter degrades gracefully: if the service is unreachable, nothing breaks.

### Contribute on every page
- Footer of every tool page: **"Found a bug? Contribute on GitHub"** → opens a pre-filled
  issue (`bug-report.md` template) with the tool name and URL.
- Landing page: **Request or contribute a tool** section at the very bottom with two
  actions — *Request a new tool* (`tool-request.md` template) and *Report an issue or
  improve a tool* (`bug-report.md` template).

### Support
- The landing page has a **Support** section with PayPal (`paypal.me/bayhaqy`) and
  Buy Me a Coffee (`buymeacoffee.com/bayhaqy`) buttons. Footers stay clean
  (copyright + views + contribute link only).

## Tech stack

- **Vanilla HTML, CSS, JavaScript** — no build step, no framework runtime, no virtual DOM.
- **Shared theme** — [`assets/theme.css`](assets/theme.css) mirrors the portfolio at
  [bayhaqy.github.io](https://github.com/bayhaqy/bayhaqy.github.io): white background, red accent
  (`#B91C1C`), black ink, Inter typography.
- **Shared shell** — [`assets/app-shell.js`](assets/app-shell.js) injects the header, footer
  (with views counter + contribute link), theme toggle, EN/ID language toggle, and toast
  helper into every app. One source of truth.
- **Web APIs** — Web Crypto API (hashes), `window.crypto.getRandomValues` (passwords),
  `Intl.DateTimeFormat` (timezones), Fetch API (DNS-over-HTTPS, GeoIP).
- **Libraries** (loaded from CDN): `crypto-js` (MD5/SHA-1), `node-forge` (X.509 parsing),
  `Leaflet` (IP map), `pdf-lib` (PDF merge), `Tesseract.js` (OCR), `Chart.js` (loan charts),
  `qrcode.js` (QR generation), `Transformers.js` (local background removal).
- **PWA** — installable on iOS/Android via `manifest.json` + `service-worker.js`.
- **APK** — TWA wrapper source in [`apk-source/`](apk-source/). Build locally with Bubblewrap.

### Cache busting convention

When you edit `assets/theme.css` or `assets/app-shell.js`, you **must** bump the `?v=`
query parameter in every HTML reference (e.g. `theme.css?v=20260831c`) **and** bump
`CACHE_VERSION` in [`service-worker.js`](service-worker.js) — otherwise returning visitors
keep the stale cached copy.

## Local development

```bash
# Clone the repo
git clone https://github.com/bayhaqy/apps.git
cd apps

# Serve locally with any static file server
python3 -m http.server 8000

# Open http://localhost:8000/ in your browser
```

No build step. No dependencies to install (other than the CDN libraries each app uses).
Edit any `index.html` and refresh — that's it.

## Deployment

The repo is deployed via **GitHub Pages** to <https://bayhaqy.my.id/apps/> through a
Cloudflare custom domain. Push to `main` and the live site updates within seconds.

The included `.nojekyll` file disables Jekyll processing so all files (including
`.well-known/` and dotfiles) are served as-is.
