Installation guide

  1. Tap "Download APK" above

    The file will download to your Downloads folder. File size is roughly 3 MB.

  2. Allow installs from this source

    If Chrome shows "For your security, your phone is not allowed to install unknown apps from this source", tap Settings → Allow from this source and toggle it on. This is a standard Android permission for APK installs.

  3. Open the APK and tap Install

    You may see a Google Play Protect warning — this is normal for any APK installed outside the Play Store. Tap Install anyway to continue.

  4. Open the Bayhaqy Apps icon

    The app will appear in your app drawer with the Bayhaqy logo. Tap it to launch — it opens fullscreen with no browser chrome, and stays connected to load the latest tools.

About the APK

The Bayhaqy Apps APK is a thin Android WebView wrapper around the live site at bayhaqy.my.id/apps/. It launches fullscreen, loads the latest tools over HTTPS, and stays in sync with the web version — no manual updates needed. The APK is signed and includes only the minimum permissions required (internet access). All app logic runs in the embedded browser, so it inherits the same privacy guarantees as the website: no embedded analytics, no third-party SDKs, and no data collection.

Source code for the wrapper is available at github.com/bayhaqy/apps — feel free to inspect, fork, or build your own.
