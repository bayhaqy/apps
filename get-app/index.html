Get the app

Two ways to install on your phone. Pick whichever fits your needs.

Progressive Web App Recommended

Installs directly from the browser. Works on both Android and iOS. No sideloading, no app store. Updates automatically when you visit the site.

  1. Android (Chrome/Edge): Open bayhaqy.my.id/apps/ → tap the three-dot menu → Install app.
  2. iOS (Safari): Open bayhaqy.my.id/apps/ → tap Share → Add to Home Screen.
  3. The app icon appears on your home screen. Launch it — it runs full-screen and works offline.
PWA is the modern standard for installing web apps. You get offline support, push notifications (future), and home-screen presence — without app store review delays.

Native Android APK Advanced

If you specifically need a real .apk file (for sideloading, MDM distribution, or devices without a browser), you can build one in ~10 minutes. The static site is wrapped with Capacitor to produce a native Android package.

  1. Install Android Studio (includes Android SDK + JDK 17).
  2. Install Node.js 18+ and the Capacitor CLI.
  3. Clone the repo, init Capacitor, add Android platform, build the APK.
# One-time setup
npm install -g @capacitor/cli

# Clone and prepare
git clone https://github.com/bayhaqy/apps.git
cd apps
npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "Apps by Bayhaqy" "id.bayhaqy.apps" --web-dir=.

# Add Android and build
npx cap add android
npx cap copy android
npx cap open android
# In Android Studio: Build → Build Bundle(s)/APK(s) → Build APK(s)

# Move the output where your download button can reach it
mv app-release.apk /apps/bayhaqy-apps.apk
Because the entire app is static HTML/CSS/JS, the resulting APK runs 100% offline from first launch — no internet permission needed beyond the initial WebView load.

Self-host

Want to host these tools on your own domain? Clone the repo and serve the static files from any web server. No build step, no environment variables, no database.

git clone https://github.com/bayhaqy/apps.git
cd apps
python3 -m http.server 8080
# Open http://localhost:8080/
